## ¿Qué he aprendido hoy?
- Entrenar una red puede resumirse en cuatro fases:
1. Forward pass
2. Calcular pérdida
3. Backward pass
4. Actualizar parámetros
- Forward pass: calcula la predicción con los parámetros actuales
- Calcular pérdida: L = (y_pred - y_true)**2
- Backward pass: ¿cómo afecta cada parámetro a la pérdida?
- nuevo parámetro = parámetro actual - learning rate × gradiente
